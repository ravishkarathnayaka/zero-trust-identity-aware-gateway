    is_finance_path

    has_finance_role

    is_dev_path
    has_engineering_role

    is_high_sensitivity
    is_encrypted
    is_patched
    is_corporate_managed
    is_valid_os

            NIST SP 800-207 Zero Trust Architecture Compliance Scorecard
          

          
Alignment across all 7 core tenets defined by the National Institute of Standards and Technology

        


        

          
          

            

              Tenet 1: All Data Sources & Services are Resources
              COMPLIANT
            

            
Every microservice endpoint (/api/finance/*, /api/dev/*) is explicitly protected with zero implicit access.

          


          
          

            

              Tenet 2: Secured Communications Regardless of Location
              COMPLIANT
            

            
Ingress terminates on HTTPS port 8443 via Envoy with PKI certificates; backends reside on internal isolated networks.

          


          
          

            

              Tenet 3: Access Granted on a Per-Session Basis
              COMPLIANT
            

            
No perimeter VPN session trust. Every single HTTP transaction is re-evaluated by ExtAuthz + OPA.

          


          
          

            

              Tenet 4: Dynamic Policy-Driven Authorization
              COMPLIANT
            

            
Dynamic authorization combining user roles, device disk encryption, OS integrity, and target sensitivity tier.

          


          
          

            

              Tenet 5: Continuous Asset Integrity & Posture Monitoring
              COMPLIANT
            

            
Unencrypted disks or outdated operating systems are conditionally rejected with immediate 403 Forbidden.

          


          
          

            

              Tenet 6: Strict Dynamic Enforcement Before Access
              COMPLIANT
            

            
Envoy configured with failure_mode_allow: false. If OPA or ExtAuthz is unavailable, the gateway strictly fails closed.

          


          
          

            

              Tenet 7: Continuous Telemetry & Asset State Collection
              COMPLIANT
            

            
Every authorization decision produces structured JSON audit logs recording subject, device posture, action, resource, and policy violations.
